# SECURE-DOC: Hybrid AES-256 & LSB Steganography Web System

SECURE-DOC is a robust web-based security application designed to ensure document confidentiality and data integrity through a combination of cryptography and steganography. Developed using **CodeIgniter 4** and **MySQL**, this system securely hides confidential documents inside standard carrier images without visibly degrading image quality.

---

## Key Features
* **Hybrid Encryption:** Implements strong cryptographic protocols utilizing **AES-256** to encrypt document payloads prior to embedding.
* **4-bit LSB Steganography:** Utilizes the Least Significant Bit (LSB) steganographic technique to seamlessly embed encrypted data into image carriers.
* **Performance Evaluation & Metrics:** Evaluates system reliability and image fidelity using quantitative metrics including **PSNR (Peak Signal-to-Noise Ratio)**, **MSE (Mean Squared Error)**, **Execution Time**, and **Avalanche Effect**.
* **File Format Support:** Handles diverse document payloads (PDF, DOCX) embedded across standard test images.

---

## Tech Stack
* **Framework:** CodeIgniter 4 (PHP)
* **Database:** MySQL
* **Security & Cryptography:** AES-256 Encryption, 4-bit LSB Steganography
* **Environment:** XAMPP / Laragon, Git
